Kapitel 3

Prompting-Grundlagen

Ob eine KI euch weiterhilft, hängt stark davon ab, wie ihr sie fragt. In diesem Kapitel lernt ihr, was einen guten Prompt ausmacht, und übt das direkt an Beispielen.

3. Sek · Medien und Informatik · 45 Min.

Etappe 1: Was ist ein Prompt?

Ein Prompt ist die Anfrage oder Anweisung, die ihr einer KI gebt, egal ob als Frage, als Auftrag oder als Beschreibung dessen, was ihr haben möchtet. Weil ein KI-Chatbot (wie ihr in Kapitel 2 gesehen habt) mögliche nächste Textstücke (Tokens) auf Basis eurer Eingabe berechnet, macht die genaue Formulierung einen echten Unterschied für das Ergebnis.

Ein unklarer Prompt führt zu einer unklaren oder wenig hilfreichen Antwort. Ein klarer, gut aufgebauter Prompt führt meistens zu einem deutlich brauchbareren Ergebnis.

Schlechter Prompt

„Schreib eine Geschichte.“

Kein Ziel, kein Thema, keine Länge, keine Zielgruppe. Das Ergebnis kann alles Mögliche sein und passt wahrscheinlich nicht zu dem, was ihr eigentlich wollt.

Guter Prompt

„Schreib eine kurze, spannende Geschichte (ca. 200 Wörter) über eine Schülerin, die ein Geheimnis entdeckt. Zielgruppe: Jugendliche. Ton: spannend, aber nicht gruselig.“

Thema, Länge, Zielgruppe und Ton sind klar. Die KI weiss genau, worauf sie hinarbeiten soll.

Etappe 2: Die Bausteine eines guten Prompts

Ein guter Prompt besteht meistens aus einer Kombination dieser vier Bausteine:

1. Ziel

Was genau soll am Ende herauskommen? Eine Zusammenfassung, eine Liste, eine Erklärung, eine Geschichte?

2. Kontext

Welche Hintergrundinformationen braucht die KI, um zu verstehen, worum es geht? Für wen ist das Ergebnis gedacht?

3. Format

Wie soll das Ergebnis aussehen? Länge, Stil, Aufbau (zum Beispiel als Liste, in Sätzen, mit Titel)?

4. Beispiel (falls nötig)

Ein kurzes Beispiel zeigt der KI, wie das gewünschte Ergebnis ungefähr aussehen soll.

Werkstatt 3Gute Aufträge formulieren

Einzelarbeit → Partnerfeedback · 15 Min. · Pflicht

Dein Prompt für die nächste Prüfung

Aus «Hilf mir in Mathe» wird ein überprüfbarer Lernauftrag. Wähle ein Thema aus eurem Unterricht. Fülle die drei Bausteine aus. Du brauchst dafür keinen echten KI-Chatbot.

Tauscht die Prompts. Markiert Ziel, Kontext und Format. Kann eine andere Person den Auftrag ausführen? Was würde zeigen, dass die Antwort hilfreich ist?

? Hilfe und mögliche Lösung

Ein prüfbarer Auftrag nennt das Thema, dein Vorwissen und die gewünschte Hilfe. Zum Beispiel: «Gib zuerst nur einen Tipp» lässt dir Denkarbeit. Prüfe Rechnungen selbst und vergleiche Erklärungen mit dem Unterrichtsmaterial. Ein guter Prompt garantiert keine richtige Antwort.

★ Bonus · Eine unpassende Antwort verbessern

Die gedachte Antwort enthält zehn Fachbegriffe und verrät sofort alle Lösungen. Schreibe eine Rückfrage, die beide Probleme gezielt behebt. Optional mit einem von der Lehrperson freigegebenen KI-Werkzeug testen.

Etappe 4: Selbsttest

Prüft kurz, ob die wichtigsten Punkte aus diesem Kapitel sitzen.

1. Was ist ein Prompt?

Genau, ein Prompt ist die Anfrage an die KI.
Die richtige Antwort: Ein Prompt ist die Anfrage oder Anweisung, die man einer KI gibt.

2. Welche Bausteine gehören zu einem guten Prompt?

Richtig: Ziel, Kontext, Format und wenn nötig ein Beispiel.
Die richtige Antwort: Ziel, Kontext, Format und wenn nötig ein Beispiel.

3. Richtig oder falsch: Die genaue Formulierung eines Prompts spielt für das Ergebnis keine grosse Rolle.

Richtig, das ist falsch! Die Formulierung beeinflusst das Ergebnis stark.
Das stimmt nicht. Die Formulierung beeinflusst das Ergebnis stark.

4. Was fehlt am ehesten im Prompt „Schreib etwas über Wale.“?

Genau, es fehlen klare Angaben zu Ziel, Kontext und Format.
Nicht ganz. Es fehlen klare Angaben zu Ziel, Kontext und Format.

5. Warum kann ein Beispiel im Prompt hilfreich sein?

Richtig, ein Beispiel zeigt der KI die gewünschte Richtung.
Die richtige Antwort: Ein Beispiel zeigt der KI, wie das Ergebnis ungefähr aussehen soll.

Kompetenzen verbinden · 10–15 Min.

Anwenden: Kreativ arbeiten und die Regie behalten

Ich kann einen Arbeitsauftrag aufteilen, zwei Entwürfe vergleichen und meinen eigenen Beitrag sichtbar machen.

Entwirf eine kleine Lernkarte zum Thema Rabatt. Zielgruppe: jemand aus deiner Klasse. Kriterien: richtige Rechnung, verständliche Sprache, eine Aufgabe zum Selbstlösen.

  1. Notiere zuerst eine eigene Idee ohne Hilfe. Formuliere dann mit dem Prompt-Baukasten einen Auftrag für einen zweiten Entwurf.
  2. Eine Partnerperson spielt den Lernhelfer und schreibt den zweiten Entwurf. Kennzeichnet dies als Rollenspiel; es ist kein echter KI-Output.
  3. Vergleiche beide Fassungen anhand der drei Kriterien. Übernimm gute Teile, korrigiere Fehler und begründe eine eigene kreative Entscheidung.
  4. Halte fest: Was erledige ich selbst, wobei hilft der Lernhelfer, was prüfe ich? Notiere verwendete Quellen und ob tatsächlich KI beteiligt war.
★ Vertiefung

Überarbeite den Auftrag nach dem Vergleich. Prüfe mit einer dritten Person, ob die neue Lernkarte besser zum Ziel passt. Ein genauer Prompt garantiert keine sachlich richtige Antwort.
